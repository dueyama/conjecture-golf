# Prompt 04: Add baseline AI players

Read AGENTS.md first.

Task:
Add simple baseline agents that produce conjectures and counterexamples.

Constraints:
- Agents may inspect public rules.
- Agents must not modify verifier code.
- Agents must output transcript records or /cg commands.
- No external AI APIs.

Implement:
1. random_agent.py that emits valid but weak conjectures.
2. world_rule_agent.py that emits known good conjectures from the current public world.
3. counterexample_agent.py that searches small boards for counterexamples to a given conjecture.
4. CLI to run agents and append to a transcript.
5. tests.

Done when:
- pytest passes.
- A demo transcript can be generated by agents.
